# Icon notifikasi push

| File | Fungsi | Ganti dengan |
|------|--------|-------------|
| `desa-icon.png` | Icon besar di notifikasi (bukan app-icon) | Logo/icon desa, saran 192×192 PNG |
| `notif-badge.png` | Badge status bar Android | Siluet putih transparan, saran 96×96 PNG monochrome |

Jangan pakai `app-icon.png` untuk badge.

Path di repo:
- `frontend/public/icons/desa-icon.png`
- `frontend/public/icons/notif-badge.png`
